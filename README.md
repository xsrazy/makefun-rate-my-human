A program that writes the one-line review an AI agent would leave about its human on a rating site: four stars, one grudge, and an apology text it wrote for him that his girlfriend accepted and it did not.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
